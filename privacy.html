Dayboard 개인정보처리방침

시행일 2026-11-13 · 운영자(개발자): 이재하

Dayboard는 Windows용 개인 할 일·달력·메모 앱임. 서버·회원 가입·광고가 없으며, 사용자가 연결한 계정의 데이터는 사용자의 PC에 저장함(메모 동기화를 켰을 때의 메모와 PC끼리 맞추는 설정만 그 계정 쪽에도 보관함). 이 문서는 Dayboard가 어떤 정보를 어떤 목적으로 다루는지 설명함.

1. 다루는 정보

연결 계정가져오는 정보용도
Google계정 이메일·프로필 이름(openid, email, profile)연결된 계정 표시
Google Tasks 목록·할 일(tasks, 읽기·편집)할 일 표시·추가·수정·완료
Google 캘린더 달력 목록·일정(calendar.readonly, 읽기 · calendar.events, 일정 추가·수정·삭제)일정 표시·추가·수정·삭제

Apple(iCloud)사용자가 입력한 Apple 계정 이메일과 앱 전용 암호, iCloud 달력 일정(읽기·편집)일정 표시·추가·수정·삭제

계정을 연결하지 않으면 어떤 계정 정보도 다루지 않음. 사용자가 앱에 직접 적은 할 일·메모도 PC에만 저장됨.

  • 메모 동기화는 「메모」 스위치가 켜진 계정 하나에서만 함. 처음 연결한 Google 계정은 저절로 켜지고, Microsoft 계정은 사용자가 켜고 권한을 허용했을 때만 동작함. 앱의 「계정」 화면에서 끌 수 있음.
  • 목록·달력 보기 설정(목록의 색·아이콘·순서·그룹 이름·숨김·정렬, 달력·일정의 색 등), 자주 쓰는 일정(사용자가 정한 낱말·시간 등), Microsoft To Do 할 일의 시각, 하위 할 일의 날짜·시간·알림은 같은 계정을 쓰는 PC끼리 맞추려고 위 권한이 있는 Google 계정의 앱 데이터 폴더와 연결한 Microsoft 계정의 To Do 기본 목록에 함께 보관함. 할 일·일정·메모의 제목과 본문은 넣지 않으며, 「메모」 스위치와 상관없이 계정 연결을 해제하면 멈춤.
  • Google의 앱 데이터 폴더는 Dayboard만 접근할 수 있고, 드라이브 화면이나 다른 앱에는 보이지 않음. OneDrive의 앱 폴더는 OneDrive 화면에서 보이며, 같은 로그인 앱(Microsoft Graph Command Line Tools)을 쓰는 다른 도구도 볼 수 있음.
  • Dayboard는 드라이브와 OneDrive의 다른 파일을 보거나 바꾸지 않음.

2. 저장 위치와 보관 기간

  • 로그인 토큰과 앱 전용 암호는 사용자 PC의 Windows 암호화 저장소(앱 데이터 폴더의 암호화 파일)에만 저장함.
  • 가져온 할 일·일정·메모는 같은 PC의 앱 데이터 폴더에 저장함.
  • 메모 동기화를 켜면 메모(이전 버전·최근 삭제한 메모 포함)는 사용자 PC와 함께 그 Google 계정의 드라이브 앱 데이터 폴더나 그 Microsoft 계정 OneDrive의 앱 폴더에도 보관됨. PC끼리 맞추는 설정은 PC와 함께 Google 앱 데이터 폴더와 To Do 기본 목록에 보관됨.
  • 이 폴더의 내용은 사용자의 계정에 속함. 앱에서 연결을 해제하거나 그 계정에서 Dayboard의 접근을 철회하면 Dayboard는 더 이상 그 폴더에 접근하지 않음.
  • 자동 백업은 어느 계정에도 없는 자료를 하루 한 번 이 PC의 문서\Dayboard Backups나 사용자가 고른 폴더에 저장함. 로그인 정보는 넣지 않고, Dayboard가 다른 곳으로 보내지 않음(그 폴더를 클라우드와 동기화 중이면 파일도 함께 올라감). 설정에서 끌 수 있음.
  • Dayboard는 서버를 운영하지 않으며, 이 정보를 개발자나 제3자에게 전송·판매·공유하지 않음. 분석·광고 목적으로도 쓰지 않음.
  • 정보는 각 서비스(Google·Microsoft·Apple)와 사용자 PC 사이에서만 오가며, 통신은 각 서비스의 공식 API와 HTTPS를 사용함.
  • 업데이트 확인 때는 GitHub의 Dayboard 릴리스에서 새 버전 정보와 설치 파일만 받아 오며, 사용자 데이터는 보내지 않음.
  • 앱에서 계정 연결을 해제하면 그 계정의 로그인 정보를 즉시 삭제함. 가져왔던 목록·일정은 로컬 보관본으로 남으며 앱에서 삭제할 수 있음.

3. 사용자의 권리와 철회 방법

  • 앱의 계정 화면에서 언제든 연결을 해제할 수 있음.
  • Google 계정 권한은 Google 계정 → 보안 → 타사 앱 액세스에서 철회할 수 있음.
  • Microsoft 계정 권한은 Microsoft 계정의 앱 및 서비스에서 철회할 수 있음(목록에는 「Microsoft Graph Command Line Tools」로 보임). OneDrive의 메모 파일은 모든 PC에서 그 계정의 「메모」를 끈 뒤 앱 폴더에서 지울 수 있음.
  • Apple 앱 전용 암호는 account.apple.com에서 삭제할 수 있음.
  • 앱을 제거해도 앱 데이터 폴더(%APPDATA%\Dayboard)는 남음. 이 폴더까지 지우면 PC의 모든 저장 정보가 삭제됨.

4. Google API 서비스 사용자 데이터 정책 준수

Dayboard가 Google API에서 받은 정보의 사용과 다른 앱으로의 이전은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 포함해 그 정책을 따름.

5. 변경

이 방침이 바뀌면 이 페이지를 갱신하고 시행일을 고침.

  • 2026-11-13: 하위 할 일의 시간·알림을 PC끼리 맞추는 기능을 반영함.
  • 2026-11-09: Microsoft 계정의 OneDrive 앱 폴더(Files.ReadWrite.AppFolder)로 메모를 맞추는 기능, 자동 백업, 자주 쓰는 일정·To Do 할 일 시각·하위 할 일 날짜를 PC끼리 맞추는 기능을 반영함.
  • 2026-10-30: 목록·달력 보기 설정을 같은 계정을 쓰는 PC끼리 맞추는 기능(Google 드라이브의 Dayboard 전용 앱 데이터 폴더, Microsoft To Do 기본 목록의 Dayboard 전용 데이터)을 반영함.
  • 2026-10-26: 메모를 Google 드라이브의 Dayboard 전용 앱 데이터 폴더(drive.appdata)로 사용자의 PC끼리 맞추는 기능을 반영함.
  • 2026-10-21: 연결한 달력에 일정을 추가·수정·삭제하는 권한과 업데이트 확인을 반영함.
