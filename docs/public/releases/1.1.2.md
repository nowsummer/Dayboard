## Dayboard 1.1.2 — 더 빠릿하게, 유리 테두리는 더 자연스럽게

- Outlook 할 일에 알림을 넣거나 지워도 저장되지 않던 문제를 고쳤어요.
- 위젯 테두리가 애플 리퀴드 글라스처럼 위쪽만 가늘게 빛나요. 위젯 예시 화면의 배경도 차분하게 바꿨어요.
- 위젯을 여는 동안 다른 동작이 멈추지 않고, 월 달력과 달력 검색이 눈에 띄게 빨라졌어요. 창을 닫아 둔 동안에는 화면을 그리지 않아요.
- 빠른 추가에서 「매주 월요일 보고」가 날짜 없는 한 번짜리 할 일로 바뀌던 문제, 주말에 「이번 주 금요일」이 지난 날짜가 되던 문제를 고쳤어요. 영어로 "tomorrow at 3"·"noon"도 읽어요.
- 이 PC의 할 일을 지우면 확인창 없이 「되돌리기」로 되살릴 수 있고, 알림 메시지가 입력칸을 가리지 않아요. 오늘 화면의 「오늘」 중복, 검색 결과 제목, 일정 카드의 「사용자 지정…」 반복, 다크 모드 메모 위젯 색, 영어 문구 몇 곳도 다듬었어요.
- 일정을 다른 달력으로 옮겨도 반복 일정의 색이 유지되고, 시작할 때 알림 확인이 실패해도 앱이 꺼지지 않아요.

### English

- Fixed reminders set or cleared on Outlook tasks not being saved.
- The widget rim now catches light only along its top edge, like Apple's Liquid Glass. The widget gallery's backgrounds are calmer too.
- Opening a widget no longer stalls other actions; the month calendar and calendar search are noticeably faster, and a hidden window stops redrawing.
- Quick add no longer turns "every monday report" into a one-off task without a date, "this Friday" on a weekend now means the coming one, and "tomorrow at 3" and "noon" are understood.
- Deleting a task on this PC is undoable without a confirmation dialog, toasts no longer cover the input box, and the Today view, search heading, custom repeat from the event card, dark note widget and a few English labels were tidied.
- Moving an event to another calendar keeps a repeating event's colour, and a failed reminder check at startup no longer closes the app.
