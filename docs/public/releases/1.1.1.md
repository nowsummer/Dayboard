## Dayboard 1.1.1 — 반복 일정을 더 안전하게, 기본 계정 고르기

- 할 일·일정을 담을 계정이 둘 이상이면 새 할 일과 새 일정이 들어갈 목록·달력을 설정에서 고를 수 있어요. 목록이나 달력을 오른쪽 클릭해 바로 정할 수도 있어요.
- 연결한 달력에서 반복 일정을 「이후 모든 일정」으로 바꾸다 연결이 끊겨도 이후 일정이 사라지지 않아요. 건너뛰거나 옮긴 날, 종료일, 다른 시간대의 요일도 그대로예요.
- Google·iCloud 달력에서 「모든 일정」으로 시각을 바꿔도 지운 회차가 되살아나지 않고, 서머타임이 바뀌는 무렵에도 시각이 맞아요. iCloud에서는 따로 고친 회차도 그대로 남아요.
- 새 일정 저장이 실패하면 「다시 시도」로 다시 보낼 수 있고, 두 번 추가되지 않아요.
- iCloud에 만든 오전 반복 일정이 하루 늦은 요일에 생기던 문제, 여러 날 종일 일정의 「하루 종일」을 끄면 첫날 한 시간짜리 일정으로 줄어들던 문제를 고쳤어요.
- 설치 파일로 업데이트할 때 실행 중인 Dayboard가 저장을 마친 뒤 닫혀요.

### English

- With two or more accounts that hold tasks or events, choose where new tasks and events go in Settings — or right-click a list or calendar.
- Changing a repeating event in a connected calendar with "This and following events" no longer loses later events if the connection drops. Skipped and moved dates, end dates and weekdays from other time zones are kept.
- In Google and iCloud calendars, changing the time of "All events" no longer brings back deleted occurrences and stays right around daylight-saving changes. In iCloud, occurrences you changed individually are kept too.
- If saving a new event fails, "Try again" sends it once more — it's never added twice.
- Fixed repeating events created in iCloud landing on the wrong day (a day late for morning events in Asia), and turning off "All day" shrinking a multi-day event to one hour on its first day.
- Updating with the installer now lets a running Dayboard save before it closes.
