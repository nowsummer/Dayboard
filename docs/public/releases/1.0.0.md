- 이 버전부터 앱 소스 코드를 이 저장소에 MIT 라이선스로 공개해요. 직접 빌드하는 방법은 README, 앱이 접근하는 파일·주소와 알려진 위험은 SECURITY.md에 있어요.
- 화면 맨 위 여백을 넉넉하게 하고 목록·달력·메모·옆 패널이 같은 높이에서 시작하도록 맞췄어요. 작은 창에서도 달력 일정이 잘리지 않아요.

- 다음 업데이트부터 바뀐 부분만 내려받을 수 있게 고쳤고, 업데이트를 확인할 때 설치마다 다른 ID를 더는 보내지 않아요.
- 계정 연결 오류 안내가 연결 화면의 안내를 가리키도록 문구를 다듬었어요.
