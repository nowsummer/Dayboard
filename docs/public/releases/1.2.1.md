## Dayboard 1.2.1 — 달력 패널 너비 조절, 모든 이모지

- 달력 오른쪽 패널의 왼쪽 경계선을 끌어 원하는 너비로 줄이거나 넓힐 수 있어요. 두 번 누르면 원래 너비로 돌아가요.
- 목록 편집의 「모든 이모지」를 누르면 Windows 이모지 창이 열려, 검색해서 어떤 이모지든 고를 수 있어요.
- 달력 목록의 서비스 로고는 여러 서비스의 달력이 함께 있을 때만 보여요. 한 계정만 쓰면 이름만 깔끔하게 보여요.

### English

- Drag the left edge of the calendar's right panel to make it narrower or wider. Double-click it to go back to the default width.
- In the list editor, All emoji opens the Windows emoji panel, where you can search for any emoji.
- The calendar list shows service logos only when calendars from more than one service are listed. With one account, you see just the names.
