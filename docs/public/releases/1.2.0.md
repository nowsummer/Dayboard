## Dayboard 1.2.0 — Mac 같은 선택 메뉴, 1년 치 달력, 조용해진 메모

- 반복·알림·목록 같은 선택 메뉴가 Mac처럼 둥글고 반투명한 메뉴로 열려요. 고른 항목에 체크 표시가 붙고, 작은 위젯 안에서도 잘리지 않아요.
- 연결한 Google·Outlook·iCloud 달력을 1년 전 일정부터 가져와요. 지난 1년 일정도 검색되고, 지난 달로 넘겨 봐도 보여요. 이 PC 달력은 날짜와 상관없이 찾아요.
- 창을 좁히면 달력 오른쪽 패널도 함께 좁아져요. 패널 아래 달력 목록에는 어느 계정 달력인지 작은 로고로 보여 줘요.
- 메모 아래에는 평소 아무것도 띄우지 않아요. 저장이나 동기화에 문제가 있을 때만 「다시 시도」와 함께 알려 줘요. 메모 위젯은 그만큼 글 쓸 자리가 넓어져요.
- 수정 창을 닫을 때 바꾼 내용이 있으면 「변경 버리기 / 계속 편집」을 물어요. 목록에서 할 일을 고르고 Alt+↑/↓로 순서를 옮길 수 있어요.
- Outlook 반복 할 일의 완료를 되돌려도 다른 기기에서 고친 내용은 지우지 않아요. 계정에 저장하는 게 늦어져도 이 PC의 할 일·일정은 기다리지 않고 바로 바뀌어요.

### English

- Pick-lists such as Repeat, Reminder and List now open as rounded, translucent menus, as on a Mac. The chosen item has a check mark, and the menu fits even inside a small widget.
- Connected Google, Outlook and iCloud calendars now come with the past year's events. You can search them and see them when you go back a few months. Search in the This PC calendar has no date limit.
- The calendar's right panel narrows with the window. The calendar list under it shows a small logo for each account's calendars.
- Notes no longer show a status line while all is well. Only a save or sync problem shows, with Try again. Note widgets get that line back for writing.
- Closing an editor with changes asks Discard changes or Keep editing. In a list, select a task and press Alt+↑/↓ to move it.
- Undoing a completed repeating Outlook task no longer removes changes made on another device. Edits on this PC no longer wait while a slow account save finishes.
