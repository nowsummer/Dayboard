## Dayboard 1.2.7 — Mac처럼 정돈된 화면과 글자 크기

- 설정과 바탕화면 위젯 화면을 Mac 시스템 설정처럼 정리했어요. 회색 묶음 안에 이름과 값이 한 줄씩 놓이고, 흰 상자 대신 값 글자를 눌러 고르며, 유리 효과 슬라이더도 Liquid Glass 모양이 됐어요.
- 위젯 달력의 오늘 표시와 빨간 글자가 Apple 캘린더의 빨강으로 바뀌었어요. 1.2.6에서 어둡게 가라앉아 보이던 예시 카드와 항상 위 위젯의 빨강·파랑도 원래대로 돌아왔어요.
- 글자 크기를 기본·크게·더 크게 중에서 고를 수 있어요. 앱은 설정에서, 위젯은 바탕화면 위젯 화면에서 따로 정하고, 앱에서는 Ctrl + = · Ctrl + - · Ctrl + 0으로도 바꿔요.
- 작은 창에서 월간 달력의 마지막 줄이 잘리거나 주간 일정의 제목과 시간이 겹치던 것을 고쳤어요. 빠른 추가는 「밤 11시」·「정오」·「다음 달 5일」처럼 적어도 알맞은 시각과 날짜로 읽어요.
- 완료한 할 일만 검색되면 바로 보여 줘요. 작은 확인 창의 겹치는 X 단추와 늘 떠 있던 안내 문구를 덜었어요.
- Electron 보안 업데이트(44.10.1)를 적용하고, Dayboard 실행 파일에서 쓰지 않는 개발자용 실행 방법을 닫았어요.

### English

- Settings and the Desktop widgets screen are laid out like Mac System Settings: grouped rows with a name and a value, values picked as plain text instead of white boxes, and a Liquid Glass slider for the glass effect.
- The widget calendar's today circle and red text now use Apple Calendar's red, and the preview cards and always-on-top widgets get back the reds and blues that looked too dark in 1.2.6.
- Choose a text size: Default, Large or Larger. Set it for the app in Settings and for the widgets on the Desktop widgets screen; in the app, Ctrl + =, Ctrl + - and Ctrl + 0 work too.
- In small windows the month view's last line is no longer cut, and week events no longer run their titles into their times. Quick add understands phrases such as "tonight at 8pm", "midnight" and "next month 5".
- A search that finds only completed tasks shows them right away. Small confirmations lose their extra X button, and fewer hint texts stay on screen.
- Includes the Electron 44.10.1 security update, and the Dayboard executable shuts developer-only ways of running it.
