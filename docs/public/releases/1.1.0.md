## Dayboard 1.1.0 — 메모 동기화, 주간·일간 달력, 리퀴드 글라스 위젯

- 메모가 Google 계정을 거쳐 내 다른 PC의 Dayboard와 맞춰져요(Google 드라이브의 숨은 폴더, 다른 앱에는 보이지 않음). 지운 메모는 「최근 삭제한 메모」에 30일 남고, 메모마다 이전 버전을 최대 10개 되살릴 수 있어요.
- 달력에 일·주 보기가 생겼어요. 일정을 끌어서 옮기거나 늘리고, 빈 곳을 끌어 새 일정을 만들고, 옆에 뜨는 카드에서 바로 고쳐요. 반복 일정은 「이 일정만·이후 모든 일정·모든 일정」으로 저장해요.
- 바탕화면 위젯이 Apple 리퀴드 글라스처럼 가장자리에서 바탕화면을 휘어 보이고, 어두운 바탕화면 위에서는 어두운 유리와 흰 글자로 바뀌어요. 유리 슬라이더의 불투명 끝은 유리 없는 카드예요.
- 메모 목록이 아이폰 메모처럼 날짜별 묶음이 됐고, 맨 위 고정·메모 안 찾기(Ctrl+F)·되돌리기와 다시 실행(Ctrl+Shift+Z)이 생겼어요. 할 일은 다른 목록으로 옮길 수 있고, 빠른 추가가 「내일 3시」「15시」「11/3」도 읽어요.
- 처음 열면 둘러보기가 화면을 짚어 가며 안내하고, 사이드바 아래 「?」에 마우스를 올리면 지금 화면의 단축키가 보여요.
- 디자인을 Apple 최신 모양에 맞춰 다듬었고, 동작마다 화면을 두 번 그리던 것을 한 번으로 줄였어요. 저장 파일이 손상되거나 설정값이 어긋나도 고쳐서 열어요.
