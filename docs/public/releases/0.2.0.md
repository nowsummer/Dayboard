## Dayboard 0.2.0 — 첫 공개 버전

- 설치형 Dayboard가 새 버전을 스스로 확인해 받아 두고, 설정의 「지금 다시 시작해 적용」을 누르면 업데이트돼요.
- 바탕화면 위젯이 Apple식 유리 카드로 바뀌었고, 유리 효과(투명~불투명)를 위젯 설정에서 바로 조절할 수 있어요.
- 목록 메뉴에서 목록을 삭제하거나 Dayboard에서만 숨길 수 있어요. Flagged Emails 같은 기본 목록은 숨기기로 정리해요.
- 바탕화면 위젯에서도 Esc와 글자 입력이 바로 동작하고, 설정은 바꾸는 즉시 적용돼요.
- 할 일 화면의 빈 여백을 줄이고 날짜 입력·반복 일정·되돌리기 등 쓰는 흐름을 전반적으로 다듬었어요.
