# Dayboard

**Windows 바탕화면에 두고 쓰는 할 일·달력·메모 앱입니다.**
Microsoft To Do·Outlook 달력, Google Tasks·Google 캘린더, iCloud 달력을 한 화면에 모아 보고, 할 일·달력·메모를 바탕화면 위젯으로 띄워 둘 수 있습니다. 서버나 회원 가입 없이 모든 데이터는 사용자의 PC에만 저장됩니다.

![Dayboard 할 일 화면](images/tasks-today.png)

## 주요 기능

- **할 일**: 오늘·예정·전체·중요 모아보기, 목록별 색과 아이콘, 목록을 묶는 그룹, 드래그로 순서 정리, 중요 표시, 알림 시각
- **달력**: 월 달력과 그날의 일정·할 일을 함께 보는 옆 패널, 날짜를 두 번 눌러 바로 일정 추가, 반복 일정, 일정별 색
- **메모**: 짧은 기록을 최근 순으로 정리하고 위젯으로 띄워 두기
- **바탕화면 위젯**: 할 일·달력·메모를 작은 창으로 띄워 바탕화면에 두거나 항상 위에 표시
- **계정 연결**: Microsoft To Do(읽기·편집)와 Outlook 달력, Google Tasks(읽기·편집)와 Google 캘린더, iCloud 달력을 연결. 달력은 읽기 전용
- **편의 기능**: 전체 검색(Ctrl+K), 화면에 맞는 새 항목 추가(Ctrl+N), 라이트·다크 테마, 한국어·영어, 오전·오후 또는 24시간 시각 표시

## 개인정보

- Dayboard는 서버를 운영하지 않습니다. 로그인 정보는 Windows 암호화 저장소에, 할 일·일정·메모는 사용자 PC의 앱 데이터 폴더에만 저장됩니다.
- 연결한 계정의 데이터는 각 서비스(Microsoft·Google·Apple)와 사용자 PC 사이에서만 오가며, 개발자나 제3자에게 전송하지 않습니다.
- 자세한 내용은 [개인정보처리방침](https://nowsummer.github.io/dayboard/privacy.html)을 참고하세요.

**Dayboard** is a personal Windows desktop app for tasks, calendar and notes. It brings Microsoft To Do / Outlook calendar, Google Tasks / Google Calendar and iCloud calendar into one window, and can pin tasks, calendar and notes to the desktop as widgets. There is no server and no sign-up: everything is stored only on your PC. See the [privacy policy](https://nowsummer.github.io/dayboard/privacy.html). The screenshots use sample data. This repository hosts the project's web pages only; it does not contain the app source or installer.
