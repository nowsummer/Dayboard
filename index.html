Dayboard

Windows 바탕화면에 두는 개인용 할 일·달력·메모 위젯 앱

무엇을 하는 앱인가

  • 할 일 목록, 월 달력, 메모를 한 창에서 보고 바탕화면 위젯으로 고정할 수 있음.
  • Microsoft To Do·Outlook 달력, Google Tasks·Google 캘린더, iCloud 달력을 연결해 같은 할 일과 일정을 Windows에서 보고 고침. iCloud 미리 알림은 지원하지 않음.
  • 개인이 만든 무료 앱이며 광고·회원 가입·서버가 없음. 모든 데이터는 사용자 PC에만 저장됨.

내려받기

  • 최신 릴리스에서 Dayboard-<버전>.exe를 내려받아 실행하면 관리자 권한 없이 설치되고 바로 시작됨.
  • 새 버전은 앱이 스스로 내려받아 두고, 설정에서 「지금 다시 시작해 적용」을 누를 때만 설치함. 버전별 변경 내용은 릴리스에 있음.
  • 서명되지 않은 새 설치 파일이라 Windows 스마트 앱 컨트롤이 몇 분 동안 막을 수 있음. 잠시 뒤 다시 실행.

화면의 할 일·일정·메모는 예시 데이터임.

Google 계정 연결에 대해

  • 「Google 계정으로 로그인」을 누르면 Google의 공식 로그인 화면이 열리고, Dayboard는 Google Tasks(읽기·편집)와 Google 캘린더(읽기, 일정 추가·수정·삭제), 계정 이메일·프로필(계정 확인)만 요청함.
  • 받은 데이터는 사용자 PC에만 보관하고(로그인 정보는 Windows 암호화로 보호) 외부로 보내지 않음. 자세한 내용은 개인정보처리방침 참조.
  • 연결 해제는 앱의 「계정 연결」 화면에서 하거나, Google 계정의 앱 권한 페이지에서 언제든 철회할 수 있음.

개인정보처리방침

Dayboard is a personal Windows desktop widget for tasks, calendar and notes. It stores all data locally on your PC and connects to Google Tasks / Google Calendar only with your consent. Download the installer from the latest release. See the privacy policy.
